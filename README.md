This mod uses QEMU to run PC emulations inside of Minecraft!
It can run Windows, Linux, And even MacOS!
# Instances
- Singleplayer ONLY (AKA, Mutiplayer is untested.)
- More then one PC at a time works!


# Supported OS's

- Linux
- Windows

## Unsupported OS's

- MacOS
(it may NEVER be supported.)

# Supported Runnable OS's

- Windows
  - Download a Windows ISO, 
and use that, you may have to 
do the workarounds to get past the 
TPM 2.0 and other workarounds.
(I used a mod called Tiny11.
It had all that stuff done 
already.)

- Linux
  - Download a Linux ISO 
and use that.

- MacOS
  - You will have to select Intel CPU
and create a Hackintosh USB. and
then put those files/folders 
into a ISO file. and use that.

- Any other
  - Other OS's should work,
unless they are not x86.

no external software needed, newer version, more features!.
- Why should you use this?

  - I would think so,

  everything is packaged together. no need other software.

- What all can i do?
  - well, you could run Windows, Linux, MacOS in Minecraft!,
  or even run your own Operating Systems!
  (a tool for making them: https://github.com/RedstoneMaster011/OperationCrafter)

# Compile From Source

- clone repo
- get a portable QEMU and move those files into /src/resources/qemu/
- then build
